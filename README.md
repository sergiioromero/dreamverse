# ✨ Dreamverse - Eventos Celestiales

Sitio web hermoso y moderno para la empresa de eventos **Dreamverse**, con una temática celestial, nubes flotantes, estrellas brillantes y animaciones fluidas.

## 🌟 Características

- ✨ **Diseño Celestial**: Gradientes azul cielo, nubes flotantes y estrellas brillantes
- 🎬 **Animaciones Fluidas**: Movimientos suaves y efectos visuales atractivos
- 📱 **Responsive Design**: Optimizado para móviles, tablets y escritorio
- 🎨 **Tailwind CSS**: Estilos modernos y personalizables
- ⚡ **Astro Framework**: Rendimiento rápido y carga optimizada
- 🌐 **SEO Ready**: Meta tags y estructura semántica

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/sergiioromero/dreamverse.git
cd dreamverse

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build

# Preview de producción
npm run preview
```

## 🎨 Personalización

### Colores
Edita `tailwind.config.cjs` para cambiar la paleta de colores celestiales.

### Animaciones
Las animaciones personalizadas están definidas en `tailwind.config.cjs`:
- `float` - Movimiento flotante vertical
- `drift` - Movimiento suave horizontal
- `twinkle` - Efecto de parpadeo de estrellas
- `fadeInUp` - Entrada suave desde abajo
- `glow` - Efecto de brillo

### Contenido
Modifica los componentes en `src/components/` para cambiar textos, servicios, etc.
