# 🌤️ DREAMVERSE

Fiestas y experiencias para gente joven en Madrid con estética celestial y vibraciones de fiesta.

## 🎨 Estilo
- Tema celeste (azul cielo, blanco, nubes)
- Tipografía joven y graffiti (Outfit)
- Galería de fiestas
- Animaciones fluidas
- 100% responsive (mobile-first)

## 🚀 Stack
- Astro
- CSS moderno optimizado
- Animaciones nativas
- Video y SVG dinámicos

## 💻 Desarrollo
```bash
npm install
npm run dev
```
